First public release of LAN Transfer. 🇧🇷 [Português abaixo](#português)

| System | File |
|---|---|
| Windows 10/11 (64-bit) | `LANTransfer-Setup-5.0.0.exe` |
| Android 10+ | `LANTransfer-5.0.0.apk` |
| Linux (64-bit) | `LANTransfer-5.0.0-linux-x64.tar.gz` |
| Mac with Intel | `LANTransfer-5.0.0-macos-intel.tar.gz` |
| Mac with Apple Silicon | `LANTransfer-5.0.0-macos-apple-silicon.tar.gz` |

**Highlights:** automatic discovery of devices on the network, direct send of files and text with accept/decline, resumable downloads, synced folders, optional PIN, HTTPS between the apps, QR code for people without the app, light/dark theme and Portuguese/English.

- **Android:** allow "install unknown apps" when opening the APK. The APK is signed with a debug key.
- **Linux/Mac:** extract and run `./lan-transfer` in a terminal. On macOS the app is not signed by Apple; run `xattr -d com.apple.quarantine lan-transfer` once before opening it.

Primeira versão pública do LAN Transfer.

| Sistema | Arquivo |
|---|---|
| Windows 10/11 (64 bits) | `LANTransfer-Setup-5.0.0.exe` |

**Destaques:** descoberta automática dos aparelhos na rede, envio direto de arquivos e textos com aceitar/recusar, downloads retomáveis, pastas sincronizadas, PIN opcional, HTTPS entre os apps, QR code para quem não tem o app, tema claro/escuro e português/inglês.

- **Android:** permita "instalar apps desconhecidos" ao abrir o APK. O APK é assinado com uma chave de debug.
